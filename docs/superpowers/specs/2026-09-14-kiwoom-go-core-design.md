# kiwoom-go 코어 + 생성기 + 국내주식 시세·차트·종목정보 설계

작성일: 2026-09-14

## 1. 문제

키움증권 REST API 의 Go 클라이언트가 없다. 공개 라이브러리로 만들어 다른 사람도 쓰게 하려는데,
**API 가 337개**라 `toss-go`(30~40개, 9,600줄)처럼 손으로 쓰면 완주할 수 없다.

## 2. 목표

- 키움 API 337개를 **전부** 다루는 공개 Go 라이브러리의 **뼈대와 생성기**를 세운다.
- 이번 범위인 국내주식 **시세·차트·종목정보 77개**가 실제로 동작한다.
- 키움이 스펙을 갱신하면 **생성기를 다시 돌려** 따라간다.

### 목표 아님

- **나머지 REST 230개** — 생성기가 서면 대부분 기계 작업이다. 별도 설계로 간다(§4).
- **실시간 WebSocket 23개 · 조건검색 8개** — 프로토콜이 달라 별건이다.
- **moneyflow 연동** — 이 라이브러리는 moneyflow 와 무관하게 선다. 쓸지는 나중에 정한다.
- **재시도·스로틀링** — 키움의 429/5xx 정책을 확인하기 전에 추측으로 넣으면 한도를 더 빨리
  태운다. 호출자 책임으로 둔다(`toss-go` 와 같은 판단).
- **모의투자 전용 기능** — 도메인만 가른다. 그 이상은 다루지 않는다.

## 3. 전제 (공식 스펙 실측, 2026-09-14)

`Kiwoom-Securities/Kiwoom-REST-API` 저장소의 `kiwoom/_data/kiwoom_api_spec.json`(3.7MB)을 분석했다.

| 항목 | 값 | 설계에 준 영향 |
|---|---|---|
| API 수 | 337 | 손으로 쓰는 선택지를 지웠다 |
| HTTP 메서드 | **전부 POST** | 전송 함수 하나면 된다 |
| 고유 URL | **29개** | 구분은 `api-id` 헤더가 한다 |
| 응답 필드 | 5,500 (LIST 그룹 309) | API 당 평균 17필드 |
| 필드 타입 | `String` 5,500 · `LIST` 309 · 그 외 2 | 타입 분기가 사실상 없다 |
| 오류코드 | 37 | 전송 계층 에러 표 |

필드 한 건의 모양:

```json
{ "element": "cur_prc", "depth": 1, "한글명": "현재가", "type": "String",
  "required": "N", "length": "20", "description": "단위: 원, 부호가 포함된 숫자" }
```

공통 헤더도 337개가 같다.

- 요청: `api-id`(필수) · `authorization`(Bearer) · `cont-yn` · `next-key`
- 응답: `api-id` · `cont-yn` · `next-key`

**이름은 지어내지 않는다.** 저장소의 예제 362개가 파일마다 구조화된 머리말을 갖고 있다.

```python
# api_id: ka10004
# api_name: 주식호가요청
# category: 국내주식
# sub_category: 시세
# template: rest
# api_url: /api/dostk/mrkcond
```

파일명(`get_domestic_stock_quote.py`)이 곧 공식 영문명이라 `api-id → 영문명` 표를 그대로 뽑을
수 있고, `template` 이 REST 와 실시간을 갈라 줘 3단계에서도 쓴다. 이번 범위 77개는 예제가
**1:1 로 전부 있다**(시세 25/25 · 차트 21/21 · 종목정보 31/31).

## 4. 전체 분할

한 번에 하지 않는다. 각 단계가 따로 설계·계획·구현을 갖는다.

| 단계 | 범위 | 비고 |
|---|---|---|
| **1 (이 문서)** | 코어 + 생성기 + 국내주식 시세 25 · 차트 21 · 종목정보 31 = **77** | `v0.1.0`. 생성기가 되는지 증명한다 |
| 2 | 나머지 REST ~230 (계좌·주문·순위정보·미국주식·ELW·ETF·업종·신용주문) | 생성기가 서면 대부분 기계 작업 |
| 3 | 실시간 WebSocket 23 + 조건검색 8 | 프로토콜이 다름 |

## 5. 구조

```
kiwoom-go/
  client.go          인증·전송·연속조회           ← 손으로
  config.go          appkey/secretkey, 도메인, env  ← 손으로
  errors.go          APIError + 오류코드 37         ← 손으로
  convert.go         문자열 변환 헬퍼               ← 손으로
  internal/spec/     스펙 JSON 사본 + 이름표 + 파서 ← 손으로(데이터는 벤더링)
  cmd/gen/           생성기                        ← 손으로
  domestic/quote/    시세 25개                     ← 생성
  domestic/chart/    차트 21개                     ← 생성
  domestic/stock/    종목정보 31개                 ← 생성
```

패키지는 스펙의 `메뉴 위치` 2단계를 따른다(`국내주식 > 시세` → `domestic/quote`). 2단계에서
`미국주식` 이 `overseas/` 로 들어올 자리를 지금부터 비워 둔다.

### 5.1 전송이 거의 공짜다

337개가 전부 POST 이고 URL 이 29개뿐이며 구분은 `api-id` 헤더가 한다. 연속조회도 전부 같다 —
응답 헤더의 `cont-yn=Y`·`next-key` 를 다음 요청 헤더에 그대로 넣는다. **함수 하나가 337개를
다 실어 나른다.** 생성되는 코드는 그 함수를 부르는 얇은 껍데기다.

연속조회는 **명시적으로** 노출한다. 응답에 `ContYN`·`NextKey` 를 싣고, 요청 옵션으로 받는다.
반복자나 자동 페이징은 넣지 않는다 — 어떤 API 가 몇 페이지까지 가는지 모르는 채로 자동화하면
사용자가 모르는 사이에 한도를 태운다.

## 6. 생성기

입력은 저장소에 **벤더링한** 두 파일이다.

- `internal/spec/kiwoom_api_spec.json` — 공식 스펙 사본(가져온 커밋 SHA 를 README 에 적는다)
- `internal/spec/api_names.json` — `api-id → 공식 영문명` 표(예제 362개에서 1회 추출)

빌드나 생성 때 원격을 받아오지 않는다. 재현 가능해야 하고, 키움이 스펙을 바꾸면 **의도적인
갱신 커밋**으로 드러나는 편이 낫다.

출력은 **API 당 파일 하나**다. 77개면 77파일. 파일이 작아 디프가 읽힌다.

```go
// Code generated by cmd/gen. DO NOT EDIT.

// GetDomesticStockQuote 는 주식호가요청(ka10004) 이다.
// 메뉴: 국내주식 > 시세 · URL: /api/dostk/mrkcond
type GetDomesticStockQuoteRequest struct {
    // 종목코드 (필수, 20자)
    StkCd string `json:"stk_cd"`
}

type GetDomesticStockQuoteResponse struct {
    // 호가잔량기준시간
    BidReqBaseTm string `json:"bid_req_base_tm"`
    // 매도10차선잔량대비
    Sel10thPreReqPre string `json:"sel_10th_pre_req_pre"`
}
```

`depth` 가 중첩을 만든다 — `depth:0` 의 `LIST` 필드가 슬라이스가 되고 `depth:1` 자식들이 그
원소 구조체가 된다. `한글명`·`required`·`length`·`description` 은 doc 주석으로 남긴다.

### 6.1 이름 규칙 — 예외를 만들지 않는다

메서드 이름은 **공식 영문명을 CamelCase 로 그대로** 옮긴다.
`get_domestic_stock_quote` → `GetDomesticStockQuote`.

패키지명과 겹쳐 `quote.GetDomesticStockQuote` 처럼 말을 더듬는다. 그래도 이 규칙을 택한 이유는,
**337개를 기계가 찍어내는 라이브러리에서는 예측 가능성이 미감보다 값어치가 크기** 때문이다.
사용자는 키움 문서에서 본 이름을 그대로 grep 해 찾을 수 있고, 생성기에 "접두사를 떼는" 예외
규칙이 들어가지 않는다.

두문자어는 **Go 린트가 문제 삼는 것만** 올린다(`ID`·`API`·`URL`·`HTTP`). `elw`·`etf` 같은
도메인 약어는 `Elw`·`Etf` 로 둔다 — 예외 목록을 키우지 않기 위해서다.

## 7. 문자열 정책

응답 필드는 **받은 그대로 `string`** 이다. 변환은 헬퍼가 맡는다.

```go
kiwoom.Decimal("+1234")  // decimal.Decimal
kiwoom.Date("20260913")  // time.Time (KST)
kiwoom.Int("0012")
```

`description` 을 읽어 타입을 자동 추론하지 **않는다.** 문구가 제각각이라 5,500개를 사람이
검수할 수 없고, 금융 데이터에서 "대체로 맞는 추론" 은 **틀린 값을 맞는 값처럼 보여주는**
실패 방식이다. 나중에 검증된 필드부터 좁혀 갈 수는 있다.

헬퍼의 규칙:

- **빈 문자열은 오류가 아니라 제로값.** 키움은 값이 없을 때 `""` 를 흔히 보낸다.
- 부호가 붙은 숫자(`"+1234"`, `"-56"`)와 앞자리 0(`"0012"`), 콤마를 한 곳에서 처리한다.
- 파싱에 실패하면 제로값과 함께 `ok=false` 를 돌려주는 짝(`kiwoom.DecimalOK`)을 함께 둔다 —
  panic 하지 않는다.

## 8. 인증·에러

OAuth2 `client_credentials` 로 `/oauth2/token` 에서 토큰을 받는다(`appkey`·`secretkey`).
응답의 `expires_dt`(YYYYMMDDHHMMSS) 기준 **만료 60초 전에 갱신**한다. 토큰 오류로 401 이 오면
**1회만** 재발급하고 다시 시도한다.

운영(`api.kiwoom.com`)과 **모의투자(`mockapi.kiwoom.com`)** 를 설정으로 가른다. 스펙이 둘 다
주므로 처음부터 지원한다.

환경변수는 `KIWOOM_APP_KEY`·`KIWOOM_SECRET_KEY`·`KIWOOM_ENV`(`prod`|`mock`, 기본 `prod`).

에러는 두 층을 `*kiwoom.APIError` 하나로 모은다.

1. 전송 계층 — HTTP 상태와 스펙의 오류코드 37개(`1501` API ID 없음 등)
2. 응답 본문 — `return_code != 0` 과 `return_msg`

`kiwoom.IsCode(err, kiwoom.CodeXXX)` 로 가른다.

## 9. 테스트

| 층 | 무엇 |
|---|---|
| 생성기 | 골든 테스트 — 스펙 조각을 넣으면 기대한 Go 코드가 나온다. 중첩(`depth`)·필수·LIST 를 덮는다 |
| `convert` | 부호·앞자리 0·콤마·빈 값·큰 수. **이 라이브러리에서 틀리면 조용한 유일한 자리다** |
| 클라이언트 | `httptest` — 토큰 발급·만료 전 갱신·401 1회 재발급·연속조회 헤더 왕복·에러 매핑 |
| 생성 결과 | 77개가 컴파일되고, 각 요청 구조체의 필수 필드가 스펙과 일치하는지 표 검증 |
| 통합 | `-tags=integration`, 실 키 필요. CI 에서 돌지 않는다 |

## 11. 위험

| 위험 | 대응 |
|---|---|
| 스펙 JSON 이 문서 스크래핑 산물이라 필드가 부정확할 수 있음 | 생성기는 스펙을 그대로 옮긴다. 틀리면 스펙이 틀린 것이고, 벤더링돼 있어 어디가 틀렸는지 추적된다 |
| 예제에 없는 API 가 나중 단계에서 나옴 | 이번 77개는 1:1 확인됨. 없으면 `api-id` 기반 이름으로 대체하고 생성기가 경고를 찍는다 |
| 문자열 그대로라 쓰기 불편하다는 반응 | 헬퍼로 완화. 자동 추론은 §7 의 이유로 하지 않는다 |
| 실 API 로 검증하지 못한 채 배포 | `v0.1.0` 은 "생성되고 컴파일되며 스펙과 일치한다" 까지만 보증한다고 README 에 적는다. 실호출 검증은 통합 테스트로 따로 |
| 337개 생성물이 저장소를 압도 | API 당 파일 하나 + `DO NOT EDIT` 헤더. 리뷰는 생성기를 보지 생성물을 보지 않는다 |
